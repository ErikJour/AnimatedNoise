Animated Noise is a 3D noise generating instrument built with C++, JUCE, and WebGPU with Dawn. The instrument UI is a navigable 3D level featuring spherical sliders for parameter control. The instrument currently features the following modules and controls:

Noise Generator:
  -Noise level
  -Noise density

Low-pass Gate:
  -Resonance
  -Decay

Amp Envelope:
  -Attack
  -Decay
  -Sustain
  -Release

Additional modules are in the works, including a state-variable filter, a randomization module for modulating parameters, and a distortion module.
